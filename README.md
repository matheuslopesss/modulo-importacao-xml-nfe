# Módulo de Importação de XML de NF-e

Este repositório apresenta a EAP do Módulo de Importação de XML de NF-e, desenvolvida como atividade da disciplina de Modelos, Métodos e Técnicas da Engenharia de Software.

## Objetivo

Organizar as principais entregas necessárias para desenvolver um módulo responsável pela importação, validação e armazenamento de arquivos XML de NF-e.
